# Лабораторная работа 7. Сортировка пузырьком

## Словесное описание

1. Проходим по массиву слева направо и сравниваем каждую пару соседних элементов.
2. Если левый элемент больше правого, меняем их местами.
3. После первого прохода самый большой элемент оказывается в конце массива — «всплывает», как пузырёк.
4. Повторяем проходы, но каждый раз на один элемент короче: конец массива уже отсортирован.
5. Если за весь проход не было ни одного обмена, массив отсортирован, и можно остановиться досрочно.

## Визуальный пример

Массив `5 1 4 2 8`:

```
Проход 1: 5 1 4 2 8 → 1 5 4 2 8 → 1 4 5 2 8 → 1 4 2 5 8 → 1 4 2 5 8   (8 на месте)
Проход 2: 1 4 2 5 8 → 1 2 4 5 8                                         (5 8 на месте)
Проход 3: обменов нет — массив отсортирован: 1 2 4 5 8
```

## Запуск

```bash
node bubble-sort.js
```

Программа просит ввести числа через пробел (или нажать Enter для случайного массива) и печатает состояние массива после каждого прохода, а в конце — количество сравнений и обменов.

## Как устроен код

- Функция `bubbleSort(source)` сортирует копию массива `[...source]`, исходный массив не меняется.
- Внешний цикл `pass` — номер прохода. Внутренний цикл идёт до `array.length - 1 - pass`, потому что последние `pass` элементов уже стоят на своих местах.
- Обмен соседей через временную переменную `temp`.
- Флаг `swapped` показывает, был ли обмен. Если нет — `break`.

## Сложность

- **Худший и средний случай:** O(n²) — примерно n²/2 сравнений (например, массив в обратном порядке).
- **Лучший случай:** O(n) — массив уже отсортирован, хватает одного прохода без обменов благодаря флагу `swapped`.
- **Память:** O(1) дополнительно — сортировка «на месте».
- **Устойчивость:** да. Равные элементы не меняются местами, потому что меняем только при строгом `>`.
