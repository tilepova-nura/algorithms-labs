# Лабораторная работа 12. Очередь

Реализована **очередь** на связном списке и программа с меню для работы с ней.

## Что такое очередь

Очередь работает по принципу **FIFO** — First In, First Out («первым пришёл — первым ушёл»), как очередь в магазине: новые элементы встают в конец, а забирают их из начала.

```
извлечение ←  [A] [B] [C]  ← добавление
             начало    конец
```

## Как устроена реализация

Очередь построена на **связном списке**: каждый элемент (`QueueNode`) хранит значение и ссылку `next` на следующий. Класс `Queue` помнит:

- `head` — начало, отсюда забираем;
- `tail` — конец, сюда добавляем;
- `length` — количество элементов.

Благодаря `head` и `tail` добавление и извлечение выполняются за O(1). Если делать очередь на обычном массиве через `shift()`, при каждом извлечении пришлось бы сдвигать все оставшиеся элементы — это O(n).

## Файлы

- `queue.js` — классы `QueueNode` и `Queue`.
- `main.js` — программа с меню и пример «касса в магазине».

Запуск:

```bash
node main.js
```

## Операции

В курсе приведены операции с очередью в Python (модуль `queue`). Здесь они реализованы вручную:

| Операция | В курсе (Python) | Здесь | Как работает | Сложность |
|---|---|---|---|---|
| Создание | `queue.Queue()` | `new Queue()` | `head = tail = null`, `length = 0` | O(1) |
| Добавление | `q.put(item)` | `enqueue(value)` | новый узел присоединяется после `tail` и становится новым `tail` | O(1) |
| Извлечение | `q.get()` | `dequeue()` | берём значение `head`, `head` сдвигается на `head.next` | O(1) |
| Первый элемент | — | `peek()` | значение `head` без удаления | O(1) |
| Проверка пустоты | `q.empty()` | `isEmpty()` | `length === 0` | O(1) |
| Размер | `q.qsize()` | `size()` | возвращает `length` | O(1) |
| Наличие элемента | `item in q.queue` | `contains(value)` | проходим по цепочке от `head` | O(n) |
| Очистка | `q.queue.clear()` | `clear()` | `head = tail = null`, `length = 0` | O(1) |
| Перебор | `for item in q.queue` | `for (const item of queue)` | генератор `[Symbol.iterator]` идёт от `head` по ссылкам `next` | O(n) |
