# Лабораторная работа 6. Двумерные массивы

Двумерный массив (матрица) — это массив строк, где каждая строка — тоже массив. Элемент в строке `i` и столбце `j` — `matrix[i][j]`.

- индексы строк и столбцов начинаются с 0, а номера в условиях — с 1;
- чтобы пройти по всем элементам, нужны **два вложенных цикла**: внешний по строкам `i`, внутренний по столбцам `j`;
- чтобы пройти **по столбцу**, внешний цикл делаем по `j`, а внутренний по `i`.

Запуск: `node task01.js` и так далее. Сначала вводятся размеры, потом матрица построчно, числа через пробел (функция `askMatrix`). Функция `printMatrix` печатает матрицу ровными столбцами.

## Задачи

| № | Условие | Как решено |
|---|---|---|
| 1 | Квадратная матрица нечётного порядка: вывести по спирали против часовой стрелки, начиная с A1,1, центральный элемент — последним | обходим «кольца» снаружи внутрь: вниз по левому столбцу, вправо по нижней строке, вверх по правому столбцу, влево по верхней строке; в центре остаётся один элемент |
| 2 | Сумма и произведение K-й строки | берём строку `matrix[K-1]`, сумма с 0, произведение с 1 |
| 3 | Номер столбца с наименьшим произведением и само произведение | для каждого столбца считаем произведение, запоминаем наименьшее и его номер |
| 4 | В каждом столбце — сколько элементов больше среднего столбца | два прохода по столбцу: сначала среднее, потом подсчёт |
| 5 | Номер первого столбца только из нечётных чисел, иначе 0 | проверяем столбец, при первом чётном — `break`; первый подходящий — ответ |
| 6 | В каждой строке поменять местами минимум и максимум | находим индексы минимума и максимума строки, меняем через временную переменную |
| 7 | Поменять местами столбцы с минимумом и максимумом всей матрицы | ищем столбцы минимума и максимума, затем в каждой строке меняем два элемента |
| 8 | Поменять местами левую верхнюю и правую нижнюю четверти (M, N чётные) | элемент `[i][j]` меняем с `[i + M/2][j + N/2]` для левой верхней четверти |
| 9 | Упорядочить строки по возрастанию первых элементов | сортировка пузырьком по первому элементу, но переставляем строки целиком |
| 10 | Суммы диагоналей, параллельных главной, начиная с одноэлементной A1,M | у элементов одной такой диагонали одинаковая разность `j − i`; перебираем её от M−1 до −(M−1) |

## Примеры

**Задача 1**, матрица 3 × 3:

```
1 2 3
4 5 6
7 8 9
```

По спирали: `1 4 7 8 9 6 3 2 5` — вниз (1 4 7), вправо (8 9), вверх (6 3), влево (2), центр (5).

**Задача 10** для той же матрицы: `3 8 15 12 7` — это суммы [3], [2+6], [1+5+9], [4+8], [7].

**Задача 8**, матрица 4 × 4 с числами 1…16: левая верхняя четверть (1 2 / 5 6) меняется местами с правой нижней (11 12 / 15 16).

## Возможные вопросы

- **Как обратиться к элементу?** `matrix[i][j]`: сначала номер строки, потом номер столбца.
- **Как пройти по столбцу?** Зафиксировать `j` и менять `i` от 0 до M−1.
- **Почему в задаче 9 можно поменять строки одним присваиванием?** Строка — это ссылка на массив. Меняя местами `matrix[i]` и `matrix[i+1]`, мы меняем ссылки, а не копируем все элементы.
- **Как устроена спираль в задаче 1?** Слой k — рамка от индекса k до M−1−k. Для каждого слоя четыре цикла по сторонам рамки. Когда k = M−1−k, остаётся центральный элемент.
