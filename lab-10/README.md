# Лабораторная работа 10. Бинарный поиск

## Словесное описание

Бинарный (двоичный) поиск находит элемент в **отсортированном** массиве, каждый раз деля область поиска пополам.

1. Задаём границы области поиска: `left = 0`, `right = n − 1`.
2. Пока `left ≤ right`:
   - находим середину `mid = ⌊(left + right) / 2⌋`;
   - если `array[mid]` равен искомому — элемент найден, возвращаем `mid`;
   - если искомое меньше `array[mid]` — оно может быть только в левой половине: `right = mid − 1`;
   - если больше — только в правой: `left = mid + 1`.
3. Если границы «перехлестнулись» (`left > right`), элемента в массиве нет — возвращаем −1.

## Визуальный пример

Ищем 23 в массиве `2 5 8 12 16 23 38 56 72 91`:

```
Шаг 1: [2 5 8 12 16 23 38 56 72 91]  середина 16, 23 > 16 → вправо
Шаг 2:                [23 38 56 72 91]  середина 56, 23 < 56 → влево
Шаг 3:                [23 38]           середина 23 — найдено, индекс 5
```

Для 10 элементов понадобилось 3 шага вместо 6 при простом переборе.

## Запуск

```bash
node binary-search.js
```

Программа просит отсортированный массив через пробел и искомое число, затем печатает каждый шаг: текущую область поиска, средний элемент и решение, куда идти дальше. Если ввести неотсортированный массив, программа сначала его отсортирует и предупредит об этом.

## Как устроен код

- `left`, `right` — индексы границ области поиска.
- `mid = Math.floor((left + right) / 2)` — индекс середины, округление вниз.
- Цикл `while (left <= right)` работает, пока область не пуста.
- Функция возвращает индекс найденного элемента или −1, а также число шагов.

## Сложность

- **O(log n)**: каждый шаг отбрасывает половину. Для 1 000 элементов — не больше 10 шагов, для 1 000 000 — не больше 20.
- Простой (линейный) поиск в худшем случае смотрит все n элементов — O(n).
- **Обязательное условие:** массив должен быть отсортирован, иначе отбрасывать половину нельзя.

## Возможные вопросы

- **Почему `right = mid − 1`, а не `mid`?** Элемент `mid` уже проверен, включать его снова не нужно. Если оставить `mid`, цикл может не закончиться.
- **Что если в массиве несколько одинаковых элементов?** Будет найден один из них, не обязательно первый.
- **Можно ли сделать рекурсивно?** Да, рекурсивная версия есть в лабораторной работе 4 (задача 5). Здесь — итеративная, с циклом.
