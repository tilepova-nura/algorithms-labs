# Лабораторная работа 2. Алгоритмы ветвления

Ветвление — это выбор одного из нескольких путей выполнения в зависимости от условия. В JavaScript для этого используются:

- `if (условие) { ... } else { ... }` — если условие истинно, выполняется первый блок, иначе второй;
- цепочка `if ... else if ... else` — когда вариантов больше двух;
- тернарный оператор `условие ? значение1 : значение2` — короткая запись «если — то — иначе» для выбора значения.

Сравнения: `===` (равно), `!==` (не равно), `<`, `>`, `<=`, `>=`. Логические операции: `&&` (и), `||` (или).

Запуск: `node task01.js` и так далее. Ввод данных — модуль `input.js`: `askNumber` (любое число), `askInteger` (целое число, можно указать допустимый диапазон), `close` (завершить ввод).

## Возможные вопросы

- **Чем отличается `===` от `==`?** `===` сравнивает и значение, и тип без преобразований, поэтому он надёжнее.
- **Как проверить чётность?** Остаток от деления на 2: `n % 2 === 0` — чётное.
- **Зачем в задаче 10 своя функция `mod`?** В JavaScript `%` для отрицательных чисел даёт отрицательный остаток (`-1 % 60 = -1`), а для лет раньше 1984 нужен остаток от 0 до 59.
- **Почему в задаче 10 цвет меняется раз в 12 лет?** Так сказано в условии: цикл из пяти 12-летних подциклов, каждый обозначен своим цветом.
