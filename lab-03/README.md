# Лабораторная работа 3. Циклические алгоритмы

Цикл — повторение одних и тех же действий несколько раз. В JavaScript:

- `for (let i = 1; i <= n; i++) { ... }` — цикл со счётчиком, когда количество повторений известно заранее;
- `while (условие) { ... }` — повторяет, пока условие истинно, когда число шагов заранее неизвестно;
- `do { ... } while (условие)` — то же, но тело выполняется хотя бы один раз (используется для повторного ввода в задаче 9).

Типичные приёмы:

- **накопление суммы**: `sum = 0`, в цикле `sum += слагаемое`;
- **накопление произведения**: `product = 1` (не 0!), в цикле `product *= множитель`;
- **следующая степень из предыдущей**: `term *= a` — не нужно каждый раз заново возводить в степень.

Запуск: `node task01.js` и так далее. Ввод — модуль `input.js` (`askNumber`, `askInteger`).

## Задачи

| № | Условие | Как решено | Пример |
|---|---|---|---|
| 1 | Стоимость 0.1, 0.2, …, 1 кг конфет | `for` от 1 до 10, вес = `i / 10`, стоимость = цена × вес | цена 250 → 0.3 кг — 75 |
| 2 | Произведение 1.1 · 1.2 · 1.3 · … (N множителей) | `product = 1`, множитель `1 + i / 10` | N=3 → 1.716 |
| 3 | N² = 1 + 3 + 5 + … + (2N − 1), печатать сумму на каждом шаге | слагаемое `2 * i - 1`, после каждого шага выводим сумму | N=5 → 1, 4, 9, 16, 25 |
| 4 | 1 + A + A² + … + Aᴺ одним циклом | `term = 1`, в цикле `term *= a; sum += term` | A=2, N=3 → 15 |
| 5 | 1 − A + A² − … ± Aᴺ без `if` | умножаем слагаемое на `-a`: знак меняется сам | A=2, N=3 → −5 |
| 6 | Числа от A до B, каждое повторить столько раз, каково его значение | два вложенных `for`: внешний по числам, внутренний повторяет | 2..4 → «2 2», «3 3 3», «4 4 4 4» |
| 7 | Незанятая часть отрезка A после укладки отрезков B, без × и ÷ | `while (rest >= b) rest -= b` | A=10, B=3 → 1 |
| 8 | Наименьшее K, при котором 1 + … + K ≥ N | `while (sum < n) { k++; sum += k; }` | N=11 → K=5, сумма 15 |
| 9 | Через сколько месяцев вклад 1000 под P % превысит 1100 | `while (s <= 1100) { s += s * p / 100; k++; }` | P=5 → 2 мес., 1102.5 |
| 10 | НОД по алгоритму Евклида | пока `b ≠ 0`: `(a, b) = (b, a % b)`; ответ — `a` | НОД(48, 18) = 6 |
