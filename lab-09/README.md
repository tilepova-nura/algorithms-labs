# Лабораторная работа 9. Сортировка выбором

## Словесное описание

1. Находим наименьший элемент во всём массиве и меняем его местами с первым элементом.
2. Теперь первый элемент на своём месте. Находим наименьший среди оставшихся (со второго до конца) и меняем его со вторым.
3. Повторяем: на шаге i ищем минимум среди элементов с i-го до последнего и ставим его на позицию i.
4. Когда неотсортированная часть сокращается до одного элемента, массив отсортирован.

## Визуальный пример

Массив `64 25 12 22 11` (в скобках — отсортированная часть):

```
64 25 12 22 11      минимум 11 — меняем с 64
[11] 25 12 22 64    минимум 12 — меняем с 25
[11 12] 25 22 64    минимум 22 — меняем с 25
[11 12 22] 25 64    минимум 25 уже на месте
[11 12 22 25] 64    готово: 11 12 22 25 64
```

## Запуск

```bash
node selection-sort.js
```

Программа просит ввести числа через пробел (или нажать Enter для случайного массива) и печатает каждый шаг: какой минимум найден и куда он поставлен.

## Как устроен код

- Внешний цикл `i` — позиция, на которую ставим очередной минимум.
- Внутренний цикл `j` от `i + 1` до конца ищет индекс минимума `minIndex`.
- Если минимум не на своём месте (`minIndex !== i`), меняем `array[i]` и `array[minIndex]`.

## Сложность

- **Всегда O(n²) сравнений** — примерно n²/2, даже если массив уже отсортирован: минимум всё равно нужно искать.
- **Обменов не больше n − 1** — это меньше, чем у пузырька. Полезно, когда перестановка элементов «дорогая».
- **Память:** O(1) дополнительно.
- **Устойчивость:** нет. Дальний обмен может переставить равные элементы: в `[2a, 2b, 1]` первый шаг меняет 2a и 1, и 2a оказывается после 2b.

## Сравнение с пузырьком и вставками

| | Пузырёк | Вставки | Выбор |
|---|---|---|---|
| Сравнения (худший случай) | ~n²/2 | ~n²/2 | ~n²/2 |
| Уже отсортированный массив | O(n) | O(n) | O(n²) |
| Обмены / сдвиги | до ~n²/2 | до ~n²/2 | не больше n − 1 |
| Устойчивая | да | да | нет |
