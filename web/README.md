# Веб-версия лабораторных работ

Страницы со всеми 12 лабораторными: можно ввести свои данные и сразу увидеть, как работает алгоритм.

## Как открыть

Дважды щёлкнуть по файлу `index.html` — он откроется в браузере. Ничего устанавливать не нужно: обычные HTML, CSS и JavaScript без библиотек.

## Что на страницах

- **Главная** (`index.html`) — список лабораторных.
- **ЛР 1–6** (`lab-01.html` … `lab-06.html`) — все задачи по порядку. В каждой задаче поля для исходных данных (уже заполнены примером), кнопка «Выполнить» и результат.
- **ЛР 7–9** — сортировки пузырьком, вставками и выбором: таблица состояния массива на каждом шаге с подсветкой отсортированной части.
- **ЛР 10** — бинарный поиск: на каждом шаге видно область поиска, средний элемент и решение, куда идти дальше.
- **ЛР 11** — двоичное дерево поиска с рисунком: добавление, поиск, удаление, обходы, информация об узле по клику.
- **ЛР 12** — очередь: добавление в конец, извлечение из начала и другие операции с наглядным отображением.

Слева — меню со всеми лабораторными, внизу страницы — переход к предыдущей и следующей.

## Устройство

- `assets/style.css` — оформление: зелёно-кремовая палитра, заголовки с засечками (шрифт Cormorant Garamond).
- `assets/app.js` — общий код: меню, построение карточек задач, разбор введённых чисел и сообщения об ошибках ввода.
- `labs/lab-XX.js` — задачи конкретной лабы: условие, поля ввода и функция `solve`, которая решает задачу и возвращает результат.
