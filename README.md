## Запуск

Нужен Node.js версии 18 или новее.

```bash
git checkout lab-01
cd lab-01
node task01.js
```

Программы спрашивают исходные данные в консоли. В папке каждой лабы есть `README.md` с условиями задач и объяснением решений.

## Веб-версия

В папке `web` — страницы для всех лабораторных: задачи по порядку, поля для ввода данных и результат сразу на странице, для сортировок, поиска, дерева и очереди — наглядная визуализация. Открыть: `web/index.html` в браузере.
